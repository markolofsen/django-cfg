# Deployment Overview

Django-CFG supports multiple deployment strategies to fit your infrastructure needs.

---

## Docker (Recommended)

The published [Docker runtime](/devops/docker-runtime) is a development environment. Follow [Quick Start](/devops/quick-start) for an owned development server. Production is separately configured and authorized: [Production](/devops/production), [CI/CD](/devops/ci-cd).

### What's Included

The canonical sample contains Django, the frontend, PostgreSQL, Redis, a loopback gateway and an optional CMDOP workspace.

## Traditional Deployment

### VPS/Dedicated Servers

**Requirements**:
- Python 3.12+
- PostgreSQL 15+
- Redis 7+
- Nginx/Apache (reverse proxy)

**Basic setup**:
```bash
# Install Django-CFG
pip install django-cfg

# Configure settings
# See Configuration Guide for details

# Run with gunicorn
gunicorn api.wsgi:application

# Start Django-RQ worker
python manage.py rqworker default high low
```

**Recommended guides**:
- [Environment Setup](./environment-setup) - Environment variables
- [Security Settings](./security) - Production security

## Infrastructure Components

All deployment methods require:

### Database
- **PostgreSQL** - Primary database (recommended)
- **MySQL/MariaDB** - Alternative option
- **SQLite** - Development only

[Database Configuration Guide →](../../configuration/database)

### Cache Layer
- **Redis** - Recommended for caching and task queues
- **Memcached** - Alternative caching backend

[Cache Configuration Guide →](../../configuration/cache)

### Background Tasks
- **Django-RQ** - Built-in task processing
- **Celery** - Alternative (requires additional setup)

[Django-RQ Integration →](/features/modules/django-rq)

### Reverse Proxy
- **Nginx** - Recommended
- **Apache** - Alternative
- **Traefik** - For Docker deployments (included)

## Background Workers

Start Django-RQ workers and scheduler for background task processing:

```bash
# Start RQ worker (listens on default, high, low queues)
python manage.py rqworker default high low

# Start the RQ cron scheduler (cron/interval schedules and delayed jobs; one per project)
python manage.py rqcron
```

## Deployment Checklist

Before deploying to production:

### Security
- [ ] `DEBUG = False` in production
- [ ] Strong `SECRET_KEY` (50+ characters)
- [ ] Configure `ALLOWED_HOSTS` with actual domains
- [ ] Enable HTTPS/SSL
- [ ] Set up CORS properly via `security_domains`
- [ ] Use environment variables for secrets

[Security Settings Guide →](./security)

### Configuration
- [ ] Database connection configured
- [ ] Redis/cache configured
- [ ] Email service configured
- [ ] Static files configured (Whitenoise or CDN)
- [ ] Media files storage configured
- [ ] Logging configured

[Environment Setup Guide →](./environment-setup)

- [ ] Health check endpoints configured
