# Django Runtime Guide

Runtime patterns specific to Django — async ORM, ASGI, and production quality standards. For generic Python patterns see [Module Design Guide](../../guides/module-design), for Django app structure see [App Design Guide](../app-design).

**WebSockets: use [django-realtime](/features/modules/django-realtime)**, django-cfg's own WebSocket layer (typed topics, `publish()`, Django auth, Redis Streams, served by the same uvicorn process). django-cfg does not use Django Channels; the Channels page below is background for projects that already run Channels.
