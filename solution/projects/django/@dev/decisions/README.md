# `decisions/` — durable design decisions

One file per decision, `NNNN-<slug>.md`: the question, the options, what was
chosen, and **why the alternatives were not**. The last part is the one that
stops the same debate reopening in six months.

A decision is not a plan. It records a constraint future work must respect,
which is why it outlives the track that raised it.
