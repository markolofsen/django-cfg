# CLI Commands Quick Reference

Fast reference guide for all Django-CFG management commands. Perfect for quick lookups!

## Quick Overview

| Task | Command | Description |
|------|---------|-------------|
| Create project | `django-cfg create-project my_project` | Initialize new Django-CFG project |
| Migrate databases | `python manage.py migrate_all` | Run migrations on all databases |
| Run server | `python manage.py runserver` | Start enhanced development server |
| Create superuser | `python manage.py superuser --email admin@test.com` | Create admin user |
| Check settings | `python manage.py check_settings` | Comprehensive diagnostics |
| Check endpoints | `python manage.py check_endpoints` | Test all API endpoints |
| Show URLs | `python manage.py show_urls` | List all registered URLs |
| Test email | `python manage.py test_email --email admin@test.com` | Send test email |
| RQ stats | `python manage.py rqstats` | Show queue statistics |
| LLM balance | `python manage.py check_llm_balance` | Check API credit balance |

## 🚀 Project Setup

```bash
# Create new project
django-cfg create-project my_project

# Show Django-CFG info
django-cfg info --verbose

# Check settings
python manage.py check_settings --verbose

# Show current configuration
python manage.py show_config --format json
```

## 🗄️ Database Operations

```bash
# Migrate all databases (recommended)
python manage.py migrate_all

# Smart migration with auto-detection
python manage.py migrator --auto

# Dry run to preview migrations
python manage.py migrate_all --check

# Migrate specific database
python manage.py migrator --database analytics_db
```

## 🏃 Development Server

```bash
# Enhanced development server
python manage.py runserver

# Custom port and host
python manage.py runserver --port 3000 --host 0.0.0.0
```

## 👤 User Management

```bash
# Create superuser (enhanced)
python manage.py superuser --email admin@example.com

# Standard Django way
python manage.py createsuperuser

# Test OTP authentication
python manage.py otp_test --email user@test.com
python manage.py otp_test --phone "+1234567890"
```

## 🧪 Testing & Monitoring

```bash
# Check all API endpoints health (auto-resolves parametrized URLs)
python manage.py check_endpoints

# Check with JSON output for CI/CD
python manage.py check_endpoints --json

# Check without automatic JWT authentication
python manage.py check_endpoints --no-auth

# Check specific endpoint
python manage.py check_endpoints --url endpoints_status

# API endpoint for monitoring
curl http://localhost:8000/cfg/endpoints/

# Test email
python manage.py test_email --email admin@test.com

# Test Telegram
python manage.py test_telegram --message "Hello!"
```

## 🌐 URLs & Routing

```bash
# Show all URLs (enhanced)
python manage.py show_urls

# Filter URLs
python manage.py show_urls --filter "api/"

# One namespace
python manage.py show_urls --namespace cfg_accounts

# List URLs (alternative)
python manage.py list_urls --api
```

## 🗺️ Sitemap & IndexNow

```bash
# Registered sitemap sources, row counts, sample URLs
python manage.py sitemap_inspect

# IndexNow: what the next run would send; records nothing
python manage.py indexnow_submit --dry-run

# One run now (new, changed and removed URLs since the last accepted run)
python manage.py indexnow_submit

# Forget the state (next run records, sends nothing), or push specific URLs
python manage.py indexnow_submit --reseed
python manage.py indexnow_submit --url https://example.com/a/ --url https://example.com/b/
```

See [IndexNow](/features/modules/django-sitemap/indexnow).

## ⏰ Cron Jobs

Commonly used commands in cron:

```bash
# Health check every 5 minutes
*/5 * * * * cd /path/to/project && python manage.py check_endpoints --json > /var/log/health.json
```

## 🔗 Command Chaining

Useful command combinations:

```bash
# Complete project setup
django-cfg create-project my_project && \
cd my_project/projects/django && \
poetry install && \
poetry run python manage.py migrate && \
poetry run python manage.py createsuperuser

# Check and migrate
python manage.py check_settings && \
python manage.py migrate_all

# Deploy workflow
python manage.py check_settings --verbose && \
python manage.py migrate_all && \
python manage.py collectstatic --noinput

# Development startup
python manage.py migrate_all && \
python manage.py runserver
```

## 💡 Tips

### Use Poetry for Project Commands

```bash
# Recommended
poetry run python manage.py runserver

# Also works
python manage.py runserver
```

### Always Check Before Deploy

```bash
python manage.py check_settings --verbose
```

### Use Dry Run for Safety

```bash
python manage.py migrate_all --check
```

### Test Integrations After Configuration

```bash
poetry run python manage.py test_email --email admin@test.com
poetry run python manage.py test_telegram --message "Deploy successful"
```
