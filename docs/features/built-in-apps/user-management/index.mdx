# User Management

Two built-in apps handle sign-in and account security. Both are registered automatically
(`django_cfg.apps.system.accounts` and `django_cfg.apps.system.totp`), so there is nothing to enable.

## Overview

| App | Module | Description |
|-----|--------|-------------|
| **Accounts** | `django_cfg.apps.system.accounts` | OTP login, JWT, OAuth, API keys, profiles, login alerts |
| **TOTP** | `django_cfg.apps.system.totp` | Two-factor authentication with authenticator apps |

---

## Accounts

**Authentication and account management**

- **Authentication** - Passwordless email OTP, token refresh
- **Social login** - Google and GitHub OAuth
- **JWT** - Access and refresh tokens with rotation and blacklist
- **Profile management** - Profile fields and avatar upload
- **Security** - Brute-force protection, login alerts, soft delete

See [Accounts](./accounts) for the endpoints, configuration and the frontend side.

---

## TOTP

**Two-factor authentication using time-based one-time passwords**

- **Setup** - QR code for authenticator apps
- **Verification** - Token check during login
- **Recovery codes** - Backup codes for account recovery

See [Two-Factor Auth](./accounts/two-factor).
