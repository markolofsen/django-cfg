# OAuth Authentication

Google and GitHub sign-in on the same endpoints and token body as the email code. Set the two environment variables of a provider and it is on; scopes, PKCE, nonce, state, redirect URIs and account linking are built in. One verified email is one user, whichever way they sign in.
