# Management Commands

## `monitor_status`

```bash
python manage.py monitor_status
```

Reports:

- Whether monitoring is enabled (it always is — zero-config).
- Whether **Telegram alerts** are on, i.e. whether a `TelegramConfig` is present
  on your `DjangoConfig`.
- Where events go: `<log dir>/djangocfg/monitor.log` with a summary of today's
  captured events when `DJANGO_CFG_LOG_DIR` is set, otherwise `stdout`.

<Callout type="info">
Retention is handled outside the app: `monitor.log` is a plain file that
`logrotate` rotates (django-cfg reopens it). There is no separate cleanup command
to run. Without `DJANGO_CFG_LOG_DIR`, events are JSON lines on stdout.
</Callout>
