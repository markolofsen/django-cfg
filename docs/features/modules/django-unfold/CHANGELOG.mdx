# What's New in Unfold Module

## November 2026: admin slim-down

django-unfold stays the admin base and is pinned `django-unfold>=0.110,<0.111`. `PydanticAdmin` / `AdminConfig` stay the main admin classes. What changed around them:

- **Dashboard REST API removed.** The Next.js dashboard and its API at `/cfg/dashboard/api/` (`statistics`, `health`, `charts`, `commands`) are gone; nothing was found calling them. The HTML dashboard tabs at `/cfg/admin/dashboard/<slug>/` remain: see [Dashboard](/features/modules/django-dashboard).
- **`SystemMonitor` removed** from `django_unfold`.
- **Icons import.** `Icons` is public as `from django_cfg import Icons` (the files live in `django_cfg/icons`). `from django_cfg.modules.django_admin import Icons` no longer works.
- **Flash messages work.** `templates/admin/base_site.html` extends `admin/base.html`, which carries the messages block, so `self.message_user(...)` and `messages.*` appear once after a redirect.
- **One `TimezoneMiddleware`.** It was listed twice in the generated `MIDDLEWARE`; it is now listed once.
- **`sqlite:////abs/path`** in a database URL is an absolute path; `sqlite:///rel/path` is relative.
- **`/favicon.ico`** is served by django-cfg (a small SVG) after the project's own routes, so a project route wins.
- **Constance** no longer imports Unfold unconditionally: without Unfold it falls back to plain fields.
- The System dashboard tab counts tables through Django's introspection, so it works on any database backend.

## Navigation Manager

`NavigationManager` builds the sidebar from the enabled django-cfg modules. It always adds **Dashboard** (Overview, Settings, Health Check, Endpoints Status; superusers), **Users & Access** (users, groups, OTP secrets, registration sources and, when GitHub or Google OAuth is enabled, the OAuth tables) and **Mail**. It adds **Currency**, **Geo**, **Payments**, **TOTP** and **Analytics** when that module is enabled (Analytics only after the first site has sent an event). Your own sections come from `UnfoldConfig.navigation`:

```python
from django_cfg import Icons
from django_cfg.modules.django_unfold.models import (
    UnfoldConfig,
    NavigationSection,
    NavigationItem,
)

unfold = UnfoldConfig(
    navigation=[
        NavigationSection(
            title="My App",
            separator=True,
            collapsible=True,
            items=[
                NavigationItem(
                    title="Products",
                    icon=Icons.SHOPPING_CART,
                    link="admin:myapp_product_changelist",
                ),
            ],
        ),
    ],
)
```

## Theme customization

The color scheme is OKLCH-based and fixed: `UnfoldConfig.get_color_scheme()` returns it (synchronized with the `@djangocfg/ui-core` CSS variables) and it goes into Unfold's `COLORS`. The `UnfoldConfig.colors` field (`UnfoldColors`) is accepted by the model but is not read when the settings are generated, so it changes nothing today. `theme` (`"light"`, `"dark"` or `None` for the user switcher) does force a mode.

```python
from django_cfg.modules.django_unfold.models import UnfoldConfig

unfold = UnfoldConfig(theme="dark")
```
