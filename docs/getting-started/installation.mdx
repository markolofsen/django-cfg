# Installation

## Install the Package

```bash
pip install django-cfg
```

Or with optional dependency groups:

```bash
pip install "django-cfg[rq]"          # Background tasks
pip install "django-cfg[full]"        # Every runtime extra (no dev tooling)
```

## Optional Dependency Groups

| Group | What it adds |
|-------|-------------|
| `rq` | Redis Queue tasks (rq 3, django-rq 4.2+, redis, hiredis) |
| `ai` | Pydantic AI agents and harness |
| `gen` | Client generator extras (openapi-python-client) and the FastAPI/SQLModel ORM generator |
| `payments` | Stripe SDK for the payments engine |
| `mcp-sql` | `pglast`, the SQL validator behind the MCP `raw_sql` tool |
| `s3` | S3-compatible [media storage](/configuration/storage) (django-storages, boto3) |
| `full` | All runtime extras above plus `pytest`, `pytest-django` and `pytest-mock`; it does not include linters, type checkers or docs tooling |
| `dev`, `test`, `docs` | Tooling for working on django-cfg itself |

A project that used `black`, `isort`, `flake8`, `mypy`, `pytest-cov`, `pytest-xdist` or `factory-boy` through the old `full` install must declare them in its own dev group.

<Callout type="tip">
Start with the base install. You can add optional groups later as your project grows.
</Callout>

## Requirements

| Tool | Version | Note |
|------|---------|------|
| Python | 3.12 or 3.13 | Required (`>=3.12,<3.14`) |
| Django | 5.2 (>=5.2.14,<6) | Not a base dependency: add it yourself or use the `django52` / `full` extra |
| Node.js | 20+ | For frontend (pnpm will be needed) |
| Docker | Latest | Optional — for local services (Redis, PostgreSQL) |

## Create a Project

```bash
django-cfg create-project myproject
cd myproject
```

This generates a project structure with Pydantic v2 configuration, auto-discovered extensions, and sensible defaults.

### Verify Installation

```bash
django-cfg --version
django-cfg info
```

## Run the Development Server

<Tabs items={['With Poetry', 'With pip']}>
  <Tabs.Tab>
```bash
cd myproject

# Install Python dependencies
poetry install

# Run migrations
poetry run python manage.py migrate

# Start the server
poetry run python manage.py runserver
# Visit http://localhost:8000
```
  </Tabs.Tab>
  <Tabs.Tab>
```bash
cd myproject

# Install Python dependencies
pip install -r requirements.txt

# Run migrations
python manage.py migrate

# Start the server
python manage.py runserver
# Visit http://localhost:8000
```
  </Tabs.Tab>
</Tabs>

## Troubleshooting

  <Tabs.Tab>

```bash
# Ubuntu/Debian
sudo add-apt-repository ppa:deadsnakes/ppa
sudo apt install python3.12 python3.12-venv

winget install Python.Python.3.12
```
  </Tabs.Tab>
  <Tabs.Tab>
```bash
# If Poetry is not available, use pip instead:

```
